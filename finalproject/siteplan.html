WDD 231 Individual Project

Writeup Vault

Professional Penetration Testing Portfolio & Write-ups

Site Name

Writeup Vault

The name Writeup Vault represents a curated collection of my cybersecurity and penetration testing write-ups. The word Vault communicates the idea of an organized repository where technical knowledge, methodologies, findings, and lessons learned are stored and presented professionally. The name is short, relevant to cybersecurity, and appropriate for a professional portfolio.

Site Purpose

Writeup Vault will serve as a professional cybersecurity portfolio focused on documenting my penetration testing work. The website will present write-ups from authorized penetration testing laboratories, vulnerable machines, CTF challenges, and other cybersecurity practice environments.

The main purpose of the site is to allow recruiters, cybersecurity professionals, students, and other visitors to evaluate my technical skills, problem-solving methodology, documentation abilities, and progression in penetration testing.

The website will include a professional home page, a dynamic library of write-ups, and an About page containing information about my skills, certifications, cybersecurity projects, and professional interests. The write-up library will allow visitors to search and filter content by characteristics such as platform, difficulty, operating system, category, and tools used. Write-up information will be retrieved from a JSON data source using JavaScript so that new entries can be added as the portfolio continues to grow.

Scenarios

  • A cybersecurity recruiter wants to determine what types and difficulty levels of penetration testing machines I have completed and evaluate how clearly I document my technical work.
  • A cybersecurity professional or student wants to find one of my write-ups related to a specific topic, such as Linux privilege escalation, web application testing, SMB enumeration, or Active Directory.
  • A hiring manager wants to learn more about my cybersecurity skills, certifications, tools, personal projects, and professional interests before considering me for a cybersecurity position.
